Skill Shelf

סקילים ותוספים (plugins) שהותקנו מעבר לקלוד הבסיסי — מקובצים לפי התוסף שאיתו הגיעו, כדי לראות בבת אחת את כל מה שתוסף מוסיף.

הרשימה מתוחזקת ידנית — כדי להוסיף או לעדכן סקיל, ערכו את index.html בריפו (או בקשו מקלוד לעשות זאת ולדחוף את השינוי).

אין כאן כלום עדיין.

חמישה דברים שצצו או צברו תאוצה אמיתית באקוסיסטם של Claude Code בחודש האחרון — מבוסס על מספרי התקנות, סיקור השקות, והדיירקטוריז שהקהילה בפועל משתמשת בהם.
